# CryptKeeper Product Steering

## Mission
CryptKeeper transforms the developer guilt of abandoned side projects into a ritual of intentional revival. Instead of letting half-finished repositories rot in silence, developers inter them in an atmospheric Graveyard, diagnose their "Cause of Death" (scope creep, burnout, auth hell, shiny object syndrome), and selectively resurrect them through focused Pomodoro sessions ("Midnight Rituals").

## Core Experience Principles
1. **Zero-Friction Local Persistence**: Everything works offline in the browser via `localStorage` with instant JSON import/export. No sign-up walls or external API keys required.
2. **Functional Spookiness (Costume Contest)**: Every gothic visual motif serves productivity:
   - Tombstones summarize dormant projects with epitaphs and days dormant.
   - Resurrecting a project moves it to the active Ritual Chamber with concrete micro-tasks.
   - Completing focus rituals burns down the wax/hourglass ring and increments revival progress.
3. **Copyright-Safe Audio Atmosphere**: Ambient soundscapes (Night Rain, Crypt Wind, Ritual Bell) are synthesized purely via the browser Web Audio API—never third-party audio files.
4. **Demo-Ready Out of the Box**: First-time visitors immediately see curated, developer-relatable sample projects and a fast `10s Demo` ritual timer option alongside standard `25m / 15m / 5m` presets.
